# 📸 Submission Screenshots Directory

Place the required submission screenshots in this `/docs` folder before submitting your repository:

1. `swagger_ui.png` — Screenshot of the interactive Swagger UI at `http://localhost:5000/api-docs` or your live Render URL `https://your-app.onrender.com/api-docs`.
2. `firestore_events.png` — Screenshot of your Firebase Console showing the `events` collection documents.
3. `firestore_tickets.png` — Screenshot of your Firebase Console showing the `tickets` collection documents.
4. `concurrency_test.png` — Screenshot of the terminal running `node test_concurrency.js` demonstrating atomic booking and rate limiting.
